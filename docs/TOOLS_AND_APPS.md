## Development and Testing

### k6

**Purpose:** Synthetic traffic and load testing.

Use k6 to generate controlled synthetic website traffic and check website stability under load. Tests can be used to evaluate:

- Response times
- Failed request rates
- Behavior under concurrent visitors
- Server CPU and memory response during traffic spikes
- Recovery after load subsides
- Overall website stability before production changes or hosting migrations

Typical testing should begin with a small number of virtual users and increase gradually rather than immediately stress-testing a production system.
